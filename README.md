# cookiekiller® portfolio

Портфолио Михаила Барашкова. React + Vite, три языка (RU / RO / EN),
контент редактируется через собственную админку на Supabase.

**Инструкция для владельца сайта:** [`docs/admin-guide-ru.pdf`](docs/admin-guide-ru.pdf)
(16 страниц, по шагам, без терминологии) или [`docs/ADMIN.md`](docs/ADMIN.md) текстом.

---

## Запуск

```bash
npm install
cp .env.example .env.local   # вписать ключи Supabase
npm run dev                  # http://localhost:5173
```

Сборка:

```bash
npm run build     # vite build + генерация sitemap.xml
npm run preview
```

Без `.env.local` сайт запустится и будет работать на статических данных
из `src/data/projects.js`. Админка в этом случае покажет экран настройки.

## Переменные окружения

| Переменная | Обязательна | Что это |
|---|---|---|
| `VITE_SUPABASE_URL` | для админки | Адрес проекта Supabase |
| `VITE_SUPABASE_ANON_KEY` | для админки | Публичный ключ `anon` |
| `VITE_SITE_URL` | нет | Адрес сайта. Нужен для `sitemap.xml` и абсолютных canonical / og:url / og:image в HTML |

Ключ `service_role` в проекте не используется и использоваться не должен.

Домен нигде в коде не зашит. Canonical-ссылки берутся из адреса, по которому открыта
страница, поэтому превью-деплои не получают чужой canonical. `sitemap.xml` требует
абсолютных адресов, и пока `VITE_SITE_URL` не задана, он просто не создаётся —
это лучше, чем карта сайта с выдуманным доменом, по которой поисковики пойдут
стучаться не туда. На продакшн-деплое Vercel адрес подхватывается автоматически
из `VERCEL_PROJECT_PRODUCTION_URL`.

## Первая настройка Supabase

1. SQL Editor → выполнить `supabase/schema.sql` (таблицы, RLS, bucket).
2. SQL Editor → выполнить `supabase/seed.sql` (двенадцать исходных проектов).
3. Authentication → Users → создать пользователя с **Auto Confirm User**.
4. SQL Editor → `select public.grant_admin('почта@example.com');`

База, созданная до появления страницы `/privacy`: выполнить `supabase/migrate-privacy.sql`
(таблица `site_texts`). Без неё страница работает на встроенном тексте, а раздел
«Политика» в админке покажет ошибку при сохранении. Для шкалы «Место в Supabase»
на Обзоре — `supabase/migrate-usage.sql`.

Подробно, со скриншотами по шагам — в PDF.

## Как устроен контент

`ContentProvider` при загрузке делает три анонимных GET к PostgREST и приводит ответ
к той же форме, что была у статического списка, — компоненты не знают, откуда пришли данные.

Порядок деградации: **Supabase → sessionStorage (10 минут) → статический список из кода.**
Пустой страницы не бывает: если база недоступна или пуста, сайт показывает исходные
двенадцать проектов.

Публичное чтение намеренно сделано на голом `fetch`, а не на `@supabase/supabase-js`:
клиент весит около 120 КБ gzip и в основном бандле ничего не делает, кроме трёх GET.
Полный клиент импортируется только админкой, которая грузится отдельным чанком.

## Безопасность

- RLS включён на всех таблицах. Чтение — всем, запись — только тем, кто есть
  в `admin_users`. Одного факта аутентификации недостаточно.
- Bucket `media`: публичное чтение, запись/удаление только для администраторов,
  лимит 200 МБ на файл.
- `/admin` закрыт от индексации через `robots.txt` и заголовок `X-Robots-Tag`.

## Что редактируется где

| Что | Где |
|---|---|
| Проекты, их тексты, медиа, порядок | админка `/admin` |
| Фон героя, фото «Обо мне», og-картинка | админка → Главная страница |
| Заголовок героя, «Обо мне», компетенции, опыт, сертификаты, контакты | `src/i18n.js` |
| Сертификаты (список) | `src/pages/Home.jsx`, константа `CERTS` |
| Политика конфиденциальности (`/privacy`) | админка → Политика; встроенный текст по умолчанию — `src/data/privacy.js` |
| og-картинка по умолчанию (1200×630) | `public/og.png` |

## Языки

Переключатель в шапке. `detectLang()` читает `localStorage` (`cc_lang`),
иначе английский. Названия брендов намеренно не переводятся: если поле
`name_i18n` для языка пустое, подставляется основное название.

## Медиа в кейсах

Галерея принимает изображения, GIF и видео. Тип определяется по MIME при загрузке
и сохраняется в базе, поэтому расширение в URL ни на что не влияет. Видео играет без звука,
по кругу, и только пока кадр в зоне видимости. Если подписаны все кадры без исключения,
под галереей появляется кликабельный индекс названий.
